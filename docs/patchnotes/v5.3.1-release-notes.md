# Release v5.3.1 — Browser Auto-Updater für Android

### Übersicht
Mit 5.3.1 erhält der **Maunting Secure Browser (MSB)** unter Android die automatische Update-Prüfung und APK-Installation direkt in der App — nach demselben bewährten Prinzip wie im Maunting Smart System (MSS).

---

### Was ist neu?

#### Maunting Secure Browser (Android)
* **In-App Update-Prüfung**: Kurz nach dem Start (oder manuell unter **Über**) prüft der Browser bei GitHub auf neuere Versionen.
* **APK-Installation auf Klick**: Ist eine Aktualisierung verfügbar, lädt der Browser die neue APK in den gesicherten Cache, verifiziert die Integrität der Datei und startet den Installationsdialog über den Android PackageInstaller (`USER_ACTION_NOT_REQUIRED` ab Android 12) bzw. den abgesicherten FileProvider.
* **Einstellungen**: Unter **Über** kann die automatische Suche beim Start jederzeit ein- oder ausgeschaltet werden.

---

### Bekannte Grenzen
* **Android: Seiten und Oberfläche teilen sich einen Prozess.** Android-WebViews einer App laufen in einem gemeinsamen Renderer ohne Trennung nach Website. Eine Webseite, die eine Sicherheitslücke in der WebView selbst ausnutzt, könnte deshalb an die Oberfläche des Browsers kommen, auch an einen entsperrten Tresor. Unter Windows ist das getrennt. Halte unter Android die „Android System WebView“ über den Play Store aktuell; die Trennung in einen eigenen Prozess folgt in einer späteren Fassung.
* Unter Android gibt es keine Erweiterungen, keine Entwicklerwerkzeuge und keinen Screenshot der ganzen Seite.
* Die Windows-Installer sind unsigniert. Vergleiche vor der Installation die Prüfsumme aus `SHA256SUMS`.
