# Hotfix v5.1.1 — Notizen und Kalender ohne Verbindung zum Server

### Übersicht
Version 5.1.1 behebt Fehler in Notizen und Kalender, die auftraten, wenn der Server nicht erreichbar war. Außerdem zeigt der Kalender in der englischen Oberfläche keine deutschen Texte mehr.

---

### Was ist behoben?

#### Notizen und Termine erscheinen sofort, auch ohne Server
* **Was passiert ist**: War der Server nicht erreichbar, blieben die Notizen bis zu einer Minute leer, nur graue Platzhalter waren zu sehen. Im Kalender stand das Raster, die Termine fehlten aber ebenso lange. Das geschah bei jedem Öffnen der Seite erneut, obwohl alles auf dem Gerät gespeichert war.
* **Was jetzt passiert**: Notizen und Termine stehen sofort da, mit dem Stand, den dein Gerät zuletzt hatte. Sobald der Server wieder antwortet, gleicht die App im Hintergrund ab.
* Betroffen waren vor allem die Desktop-App und die Android-App.

#### Keine doppelten Notizen und Termine mehr
* **Was passiert ist**: Wer beim Speichern mehrmals schnell auf „Notiz erstellen“ oder „Speichern“ klickte, legte mehrere Einträge an. Ohne Server zeigte das Gerät zunächst nur einen. Sobald der Server wieder erreichbar war, tauchten die Kopien auf, und wer eine davon löschte, bekam die anderen zurück.
* **Was jetzt passiert**: Jeder Speichervorgang legt genau einen Eintrag an, egal wie oft geklickt wird.
* Bereits entstandene Kopien bleiben bestehen. Lösche sie bei Bedarf einzeln.

#### Kalender in Englisch
* Wochentage, „Today“, „New event“, „Create event“, „No events“, die Zahl der Termine in der Tagesansicht und „+N more“ an vollen Tagen der Monatsansicht erscheinen jetzt auf Englisch, wenn die Oberfläche auf Englisch steht. Bisher standen dort deutsche Texte.
* Der Pfeil zum nächsten Monat heißt für Bildschirmleser jetzt „Weiter“ bzw. „Next“.

#### Lange Terminnamen
* In der Tagesansicht ragten sehr lange Terminnamen auf dem Handy über den Rand der Karte hinaus. Sie brechen jetzt um.
