# Hotfix v5.1.2 — Einstellungen ohne Verbindung zum Server

### Übersicht
Version 5.1.2 macht die Einstellungen der Desktop-App und der Android-App auch dann erreichbar, wenn der Server nicht antwortet. Was auf deinem Gerät gespeichert ist, kannst du jetzt jederzeit ändern.

---

### Was ist behoben?

#### Einstellungen auch ohne Server
* **Was passiert ist**: War der Server nicht erreichbar, verschwand „Einstellungen“ aus dem Profilmenü und aus dem Menü am Handy. Wer trotzdem dorthin wollte, landete im Tresor, im Kalender oder in den Notizen. Mikrofon, Lautsprecher, Wake-Word, Tastenkürzel, Autostart oder die Messenger-PIN ließen sich so nicht umstellen, obwohl all das nur auf deinem Gerät liegt.
* **Was jetzt passiert**: Die Einstellungen sind immer erreichbar. Warst du zuletzt dort, öffnet die App sie auch beim Start ohne Server wieder.
* **Ohne Server nutzbar**: App bzw. Desktop-Integration, Audio und Wake-Word, Sicherheit (Messenger-PIN, Tresor-Sperre, Biometrie), Rechtliches und Gefahrenzone.
* **Braucht den Server**: Konto (Zeitzone, Standort, Profilbild, Datenexport) und Freunde & Meilensteine. Diese Reiter tragen offline ein durchgestrichenes WLAN-Symbol und zeigen „Braucht Verbindung zum Server“. Sobald der Server wieder antwortet, erscheinen sie ohne Neuladen.

#### Kamera-Sicherung (Android)
* Ohne Server lässt sich die Kamera-Sicherung nicht ein- oder ausschalten. Einschalten braucht die Bestätigung durch den Server, und Ausschalten würde dort sonst einen Zugang stehen lassen. „Nur über WLAN“, Bildschirmfotos und „Vorhandene sichern“ bleiben offline nutzbar.

#### Impressum ohne Server
* Unter „Rechtliches“ stand ohne Server beim Impressum „inaktiv“, auch wenn es eingerichtet ist. Dort steht jetzt „Offline“.

---

### Was du tun musst
* **Desktop-App und Android-App auf 5.1.2 aktualisieren.** Am Server ändert sich nichts, er zeigt nach dem Update nur die neue Versionsnummer.
