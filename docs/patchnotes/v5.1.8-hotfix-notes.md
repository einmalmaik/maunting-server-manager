# Hotfix v5.1.8 — APK-Update für Android repariert

### Übersicht
Auf Android-Geräten schlug die Aktualisierung auf neuere Versionen fehl. Nach dem Download meldete das Betriebssystem häufig „App konnte nicht installiert werden“. Dieser Hotfix behebt die Ursachen im Update- und Installationsprozess.

---

### Was ist neu & verbessert?

#### Zuverlässiger Download großer Update-Pakete
* **Was passiert ist**: Der integrierte Updater hatte für den gesamten Download ein Zeitlimit von 15 Sekunden. Bei einer Dateigröße von über 100 MB brach die Verbindung auf mobilen Daten oder bei durchschnittlichem WLAN ab. Weil der Stream-Abbruch nicht als Fehler gewertet wurde, speicherte die App die unvollständige Datei ab und versuchte sie zu installieren.
* **Was jetzt passiert**: Große Downloads haben kein starres Gesamtlaufzeit-Limit mehr. Sie brechen nur ab, wenn die Verbindung für mindestens 60 Sekunden abreißt. Bricht eine Übertragung ab, wird die unfertige Datei gelöscht und der Fehler im Updater angezeigt.

#### Integritätsprüfung vor der Installation
* Die heruntergeladene Datei wird vor dem Start der Installation auf Gültigkeit geprüft:
  * Mindestgröße (vollständiges Release-Paket)
  * Gültiger ZIP-Archiv-Header
  * Vorhandener End-of-Central-Directory-Eintrag am Dateiende
* Sollte sich noch eine beschädigte oder unfertige Datei aus einem früheren Update-Versuch im Zwischenspeicher befinden, wird diese automatisch erkannt, gelöscht und sauber neu geladen.

#### Installationsprozess für Android angepasst
* Die Übergabe an den Android `PackageInstaller` nutzt jetzt die standardkonforme Bezeichnung `base.apk`. Dadurch verwerfen herstellereigene Paketmanager auf Samsung- oder Xiaomi-Geräten die Installationssitzung nicht mehr vorzeitig.
* Wenn eine Installationssitzung fehlschlägt, wird sie ordnungsgemäß geschlossen, bevor auf den Systemdialog ausgewichen wird.
* Bricht der Nutzer eine Aktualisierung im Bestätigungsdialog manuell ab, wird das respektiert und kein doppelter Dialog eingeblendet.

---

### Was du tun musst
* **Android-Nutzer**: Falls dein Gerät noch auf einer Version vor 5.1.8 ist und das automatische Update blockiert war, installiere Version 5.1.8 einmalig manuell über die bereitgestellte APK-Datei. Ab Version 5.1.8 funktionieren automatische Updates wieder zuverlässig.
* **Server-Betreiber**: Aktualisiere das Panel wie gewohnt auf Version 5.1.8.
